# JS 4All — интерактивный курс JavaScript

**Версия исходников:** 1.2.0  
**Содержание:** 10 глав, 35 уроков, 200+ проверок решений. Незавершённых пунктов «Скоро» нет.

JS 4All — русскоязычный интерактивный курс современного JavaScript (ES2015+). Структура глав вдохновлена книгой Марейна Хавербеке «Выразительный JavaScript», но тексты и задания написаны заново. См. лицензионное примечание в конце файла.

## Запуск

Самый надёжный вариант — локальный HTTP-сервер или статический хостинг. Для запуска достаточно установленного Node.js — установка пакетов не требуется:

```bash
npm start
```

Откройте `http://127.0.0.1:8000`. Для публикации подойдёт GitHub Pages: загрузите содержимое проекта в корень репозитория и выберите **Settings → Pages → Deploy from branch → main / root**.

В релизном архиве есть предварительно собранный `js/bundles/main.js`, поэтому сайт работает без сборки. Если меняете исходники и хотите пересобрать bundle, выполните `npm install`, затем `npm run build`.

## Проверки перед публикацией

```bash
npm test
npm run build
```

Тестовый набор проверяет:

- наличие всех глав и уроков, уникальность ID и отсутствие незаполненных разделов;
- наличие теории, задания, подсказок, решения и тестов у каждого урока;
- прохождение всех встроенных тестов каждым эталонным решением;
- сохранение, импорт и экспорт прогресса, фильтрацию неизвестных ID и приоритет импортированных черновиков;
- 120+ запускаемых примеров теории, включая проверку двух намеренно ошибочных примеров;
- свежесть сборки bundle по сравнению с исходниками.

## Как устроено выполнение кода

Примеры и задания выполняются в изолированном Web Worker с ограничением времени. В Worker отключены распространённые сетевые и хранилищные API, чтобы уменьшить случайные побочные эффекты. **Это не полноценная граница безопасности для запуска враждебного кода.**

Для уроков с DOM (события, формы, canvas) используется iframe с `sandbox="allow-scripts"` и `srcdoc`: код ученика и тесты выполняются внутри iframe в уникальном origin, а результат возвращается через `postMessage`.

Прогресс и черновики сохраняются в `localStorage` текущего браузера. Их можно перенести кнопками «Скачать прогресс» и «Загрузить прогресс». Импорт не принимает неизвестные ID уроков, а импортированный черновик заменяет локальный черновик того же урока.

## Структура проекта

- `index.html`, `css/book.css` — оболочка и оформление;
- `js/main.js` — маршрутизация, оглавление, рендеринг уроков и проверка заданий;
- `js/engine/` — запуск кода, форматирование вывода и тестовый API;
- `js/ui/editor.js` — редактор CodeMirror 6 с запасным текстовым полем;
- `js/core/state.js` — прогресс, черновики, импорт и экспорт;
- `js/course/` — все 10 глав и 35 уроков;
- `tests/course-smoke.test.js` — автоматические проверки учебного контента;
- `tests/bundle-fresh.test.js` — проверка свежести сборки.
- `tests/bundle-fresh.test.js` — проверка, что сборка bundle соответствует исходникам.

## Как добавить урок

В файл нужной главы `js/course/chN.js` добавьте объект в `lessons`:

```js
{
  id: 'unique-id',
  t: 'Название урока',
  th: `<p>Теория простыми словами</p>${run('console.log(1 + 1)')}`,
  task: {
    text: 'Что нужно сделать',
    starter: 'function answer() {\n  // ваш код\n}\n',
    tests: `test('пример', () => eq(answer(), 42));`,
    hints: ['Первая подсказка', 'Вторая подсказка'],
    solution: 'function answer() {\n  return 42;\n}'
  }
}
```

Используйте `run()` для запускаемых примеров, `c()` для отображения фрагментов кода. Избегайте необработанных обратных кавычек внутри HTML-шаблона: для кода в HTML используйте `<code>...</code>`, а буквальное `${...}` записывайте как `\${...}`.
