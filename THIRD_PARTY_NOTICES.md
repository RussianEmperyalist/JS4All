# Сторонние материалы и лицензии

- **«Выразительный JavaScript» / Eloquent JavaScript**, автор Marijn Haverbeke. Структура курса вдохновлена книгой; тексты и задания JS 4All написаны заново. В README исходного проекта указана лицензия CC BY-NC 3.0 для книги. JS 4All не является официальным продуктом автора.
- **CodeMirror 6** и связанные пакеты `@codemirror/*`, `@lezer/highlight` — сторонние зависимости, объявленные в `package.json`. Перед распространением проверьте актуальные лицензии установленных версий и сохраните соответствующие уведомления.
- JavaScript и браузерные API предоставляются средой выполнения браузера и Node.js; проект не включает серверную часть.

Этот файл не заменяет юридическую проверку лицензий перед коммерческим использованием.
